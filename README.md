# 페르시아의 왕자 전사의 길 (GC) 한글 패치

게임큐브 북미판 *Prince of Persia: Warrior Within* (`G2OE41` 리비전 0)용 비공식 한국어 패치입니다.

첫 릴리즈 **v1.0** · [릴리즈 안내](release/v1.0.md)

- 오프닝과 게임 중 대사 자막 350줄에 한국어를 적용했습니다. 자막 표시 시간은 게임큐브판과 같습니다.
- 메뉴, 메모리 카드, 조작 안내, 지도와 목표, 무기, 시간의 힘 설명을 한글화했습니다.
- 워헤이븐 Regular를 20px 원본 비율로 그렸습니다. 메모리 카드 안내의 행간을 넓히고 옵션·난이도 제목을 가운데에 배치했습니다.

본인이 소유한 디스크에서 만든 원본 이미지가 필요합니다.

## 사용자용 패치 적용

### 준비물

- 북미판 게임큐브 원본 이미지 (`G2OE41` 리비전 0).
- Windows 10 또는 11 64비트. 기본 Windows PowerShell과 ZIP에 동봉한 도구를 사용합니다.

| 원본 형식 | 결과 | 비고 |
| --- | --- | --- |
| ISO, GCM | 원본과 같은 형식 | 바로 적용 |
| CISO, WIA, WDF, GCZ | 원본과 같은 형식 | 동봉한 wit으로 ISO에서 패치한 뒤 원래 형식으로 저장 |
| RVZ | ISO로 변환한 뒤 적용 | Dolphin의 게임 목록에서 변환 |
| NKit | 원본 ISO로 복원한 뒤 적용 | NKit 도구로 복원 |

패처는 디스크의 파일 목록으로 변경 대상 파일을 찾고, 해당 파일의 크기와 내용을 검증합니다. 디스크 내부의 파일 위치나 빈 영역의 내용이 달라도 파일이 온전하면 적용할 수 있습니다.

### 적용 방법

1. 패치 ZIP `G2OE_KPatch_v1.0.zip`을 풉니다.
2. 푼 폴더에 원본 이미지를 두고 `패치하기.bat`을 실행합니다. 원본 파일을 배치 파일 위로 끌어 놓아도 됩니다.
3. 원본과 같은 폴더에서 파일명 끝에 ` (KOR)`가 붙은 이미지를 엽니다.

자세한 사용법과 오류 안내는 ZIP 안의 `README.txt`에 있습니다.

### 실행 환경

Dolphin에서 확인했습니다. 영어 언어 설정에서 한글이 표시됩니다. 자막을 켜려면 **옵션 → 화면 → 자막 → 예**를 선택하세요.

### 알려진 한계

일부 디스크 오류 전용 화면, 오프닝 영상의 고지, 엔딩 크레딧, 디스크 배너 및 저장 데이터 설명에는 영문이 남아 있습니다.
