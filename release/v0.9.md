## 바뀐 점

게임큐브 북미판 `G2OE41`용 첫 한글 패치입니다.

- 컷신 및 게임 중 대사 자막 350줄을 한글화했습니다. 음성과 자막 표시 시간은 원본과 같습니다.
- 메뉴, 메모리 카드 안내, 조작법, 지도와 목표, 무기와 시간의 힘 설명을 한글화했습니다.
- 워헤이븐 Regular의 원래 획 비율을 살리고 메모리 카드 안내의 행간과 두 메뉴 제목의 위치를 조정했습니다.

## 적용 방법

| 원본 형식 | 결과 |
| --- | --- |
| ISO, GCM | 같은 형식 |
| CISO, WIA, WDF, GCZ | 동봉한 wit으로 변환 후 같은 형식 |
| RVZ, NKit | 원본 ISO로 변환 또는 복원 후 적용 |

1. `G2OE_KPatch_v0.9.zip`을 풉니다.
2. 북미판 원본 이미지를 같은 폴더에 두고 `패치하기.bat`을 실행합니다. 원본을 배치 파일 위에 끌어 놓아도 됩니다.
3. 원본과 같은 폴더에 파일명 끝에 ` (KOR)`가 붙은 이미지가 생깁니다. 대사 자막은 게임의 **옵션 → 화면 → 자막 → 예**에서 켭니다.

Dolphin과 Wii U + Nintendont에서 실행을 확인했습니다. Wii U의 UWUVCI 주입 테스트도 마쳤습니다.

동봉 도구의 소스는 [Wiimms ISO Tools](https://download.wiimm.de/source/wiimms-iso-tools/), [Cygwin 패키지](https://cygwin.com/packages/), [xdelta3 3.1.0](https://github.com/jmacd/xdelta-gpl/tree/v3.1.0)에서 확인할 수 있습니다.
