# 빌드와 번역 수정

## 빌드 입력

디스크 ID가 `G2OE41`인 북미판 원본 ISO와 워헤이븐 Regular 글꼴을 사용합니다. 이 프로젝트에서 정본을 재현할 때는 `work/original.iso`를 입력으로 쓸 수 있습니다.

## 번역 데이터

- `menu.json`은 메뉴 파일명 아래에 `태그 번호:줄 번호`로 한국어를 지정합니다. 번호는 0부터 세며, 원본 메뉴에서 `LABEL`과 `STRING` 태그를 순서대로 읽습니다. 같은 원문이 여러 화면에 나오면 해당 한국어가 함께 적용됩니다.
- `system.json`은 문자열 테이블의 16진수 리소스 키와 0부터 세는 줄 번호로 문구를 지정합니다. 버튼과 줄바꿈을 나타내는 기존 제어 코드를 보존합니다.
- `dialogue.json`은 `인덱스 리소스 키/문자열 리소스 키`와 줄 번호로 대사를 지정합니다. JSON의 줄바꿈을 게임의 줄바꿈으로 변환하며 표시 시간은 원본 ISO에서 읽습니다.

## 검증 범위

Dolphin에서 메모리 카드 안내와 메뉴, 첫 전투 안내, 오프닝 자막을 확인했습니다. 영어 자막 리소스는 ISO에서 읽어 번역과 원래 표시 시간을 확인했습니다. 디스크 오류 전용 화면, 영상에 들어 있는 저작권 표기와 크레딧, 일부 디스크·메모리 카드 제목은 영문입니다.

릴리즈 패치는 `tools/make_patcher.py`에서 원본과 한국어 ISO를 대조해 생성합니다. 사용자용 패처는 ISO 전체의 SHA-256 대신 디스크 ID와 매니페스트에 기록된 변경 대상 게임 파일을 확인합니다.
